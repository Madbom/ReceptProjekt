# ReceptProjekt# Receptsajten

A responsive recipe website built with semantic HTML5 and modern, mobile-first CSS.

## Features
- **Home Page (`index.html`):** Hero banner, category filter pills, and a responsive recipe card grid.
- **Recipe Page:** Detailed recipe layout featuring preparation facts, interactive ingredient checkboxes, step-by-step instructions, and serving suggestions.
- **Share a Recipe (`dela-recept.html`):** Accessible submission form built with `<fieldset>`, `<legend>`, native HTML5 validation, and responsive multi-column fields.
- **Accessibility:** Includes a skip-to-content link, ARIA labels, keyboard `:focus-visible` states, and high-contrast typography.

## Technologies Used
- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<main>`, `<fieldset>`, `<footer>`) and native form validation.
- **CSS3:** Custom properties (CSS variables), native CSS nesting, Flexbox, CSS Grid, and mobile-first media queries.
